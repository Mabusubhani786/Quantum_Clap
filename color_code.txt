Core Color Roles
Role	Hex	Usage
Background (Global)	#FAFAFF	Main canvas behind all content. Your note: content bg stays white — this is the white.
Header Background	#1C1C1C	Primary dark charcoal. Not pure black, but your designated black.
Surface / Cards	#FFFFFF	Cards, modals, side panels.
Secondary Surface	#EEEFF2	Subtle section dividers, disabled states, hover backgrounds on white.
Accent / Highlight	#DADDD8	Soft green-gray. Use for: active filters, selected state, progress bars, subtle badges.
Warm Accent (Caution / Save)	#ECEBE4	Watchlist button, bookmark icon, “you might like” separators.
Text & Icon Hierarchy
Purpose	Hex	Notes
Primary text (dark mode header)	#FAFAFF	On #1C1C1C header.
Primary text (light mode content)	#1C1C1C	On #FAFAFF or #FFFFFF.
Secondary text	#6E6E73	Descriptions, dates, cast subtext. Use #DADDD8 tone to derive.
Tertiary / Placeholder	#9A9C94	Search hints, empty states.
Icons (default)	#1C1C1C	On light bg.
Icons (header)	#FAFAFF	On dark header.
